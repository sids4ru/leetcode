### How to Get Started 🛠️

It’s as easy as pie!

1. Open up the `Index.html` file.
2. Run it on your favorite browser.
3. **Pro Tip**: To host the code locally, you’ll need to use an HTTP server. No worries, it’s super easy to set up!

You can get started with the `http-server` package from npm:
```
npm install http-server -g
```
Then, in the directory where your solutions are stored, simply run:
```
http-server
```
Boom! You’re ready to go!
